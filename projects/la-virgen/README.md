# LA-VIRGEN — материалы проекта

Загружай в эту папку исходные материалы для страницы проекта:
- фотографии JPG / PNG / WebP;
- короткие видео или ссылки на видео;
- текстовые файлы с описанием, задачей, концепцией, материалами и годом.

## Как обновлять сайт
1. Добавь новые файлы в эту папку через **Add file → Upload files**.
2. Напиши в ChatGPT: **«Обнови проект LA-VIRGEN на сайте из папки projects/la-virgen»**.
3. Я просмотрю доступные материалы и обновлю страницу проекта, сохраняя утверждённый дизайн.

## Рекомендации
- Имена файлов делай понятными: `01-cover.jpg`, `02-detail.jpg`, `03-process.jpg`.
- Для главной фотографии используй имя `cover.jpg`.
- Сами по себе загруженные файлы страницу не меняют: обновление страницы выполняется отдельным коммитом.
