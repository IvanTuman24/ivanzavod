# ZAVOD website

Responsive brutalist portfolio starter for ZAVOD.

## Publish
1. Open repository **Settings → Pages**.
2. Set **Build and deployment → Source** to **GitHub Actions**.
3. The workflow in `.github/workflows/pages.yml` deploys on pushes to `main`.
4. When the workflow succeeds, the live URL appears in **Settings → Pages**.

Project cards are placeholders; replace them with verified project names and original photography before treating the portfolio as complete. Keep the Tilda site online until the new version is tested.
